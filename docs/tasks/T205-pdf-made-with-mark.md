# T205 — A small "Made with TroubaStack" mark on exported PDFs (on by default, can be switched off)

Owner: web-core. Spec: Fable, 2026-10-25. Small.

## Why (VLL)

> "could be nice if the pdf produced have a small optional marking at the bottom of the page (activated by default)
> saying something Generated by TroubaStack or something"

## Scope: exported documents ONLY

The mark goes on the PDFs a person downloads to print or hand over:

| PDF | Code |
|---|---|
| The concert print (T57/T202, member-scoped) | `bake/pdf.go` `writeA4PDF` → `ConcertPDF` |
| The single-file print (FILEPDF) | `bake/filepdf.go` → `writeA4PDF` |
| The running order (T158) | `setlistpdf.Render` |
| The sound sheet (T203) | `soundsheet.RenderPDF` |

**NOT on generated charts** (`chartpdf.Render`). Those PDFs ARE the source the bake rasterizes for the tablets.
Marking them would change every chart page's raster hash, flag every rehearsal note "not in the current bake", and
put branding on the stage display. Pin that with a test (below).

## The mark

- One line, small (about 6–7 pt), muted grey, at the bottom of EVERY page.
- Placed so it never overlaps the existing footer: below or beside the concert/page footer, at the bottom-right
  corner, within the page margin.
- **Default text:** "Made with TroubaStack". It is a product word, so it goes on the docs-stage label list (VLL's
  words were "Generated by TroubaStack").
- Plain text, no logo image (a logo would change the file size and determinism for nothing).
- **Output stays deterministic:** same input + same setting = same bytes.

### Labels (product words — on the list)

The mark is a product word; it must not change as a side effect of another commit. On the list for VLL to confirm:

| Surface | Shipped default | VLL's original phrasing |
|---|---|---|
| PDF mark (`pdfmark.DefaultText`) | **Made with TroubaStack** | Generated by TroubaStack |
| Band settings checkbox | Show "Made with TroubaStack" at the bottom of exported PDFs | — |

Kept in `pdfmark.DefaultText` as the single source. Final copy may be tuned at the gate / the documented-feature stage.

## The setting

- **Band level, admin-edited:** "Show 'Made with TroubaStack' on printed PDFs", ON by default.
- **Store it as `Band.HidePdfMark bool`.** The zero value means shown, so every existing band gets the default with
  no migration.
- It goes in band settings in Studio (one checkbox), is carried by `.tband` (`band.json`, additive), and is read by
  all four renderers through their callers.
- An optional per-download override is not needed now.

## Tests

- **Each of the four renderers:** with the setting at its default, every page contains the mark text (extract it
  with poppler `pdftotext` in the test, or assert on the renderer's text calls). With `HidePdfMark`, no page
  contains it.
- **Generated charts never carry it:** `chartpdf.Render` output contains no mark, whatever the band setting, and the
  baked raster hash of a generated chart is unchanged by toggling the setting. This is the guard against the bake
  churn above.
- Determinism: two renders with the same setting give identical bytes.
- **`.tband` round-trip** carries `hidePdfMark`.
- The Studio setting: admin-only (a member gets 403), and the e2e toggles it.

## Out of scope

Branding in the app UI, links or QR codes in the PDF. A QR code to the site could come later, if VLL wants it.
