TroubaStack

Sheet music for your band — shared, marked up together, and ready on stage.

TroubaStack keeps your band’s songs in one place. Everyone marks up the same charts from a web browser. Before a gig, the setlist becomes one file, and each musician reads it on a tablet — even with no internet.

  • Free and open source
  • Runs on a server you own
  • Android app for the stage

Charts

Bring a PDF — or type the chords

Each song holds its files: a lead sheet, a guitar tab, a drum part. Upload the PDFs you already have, or write a chart as plain text — chords on one line, lyrics under them — and TroubaStack lays it out as a clean page.

  • Change the key of a typed chart in one step — your marks stay on their words.
  • Two columns for long songs, so the text stays large.
  • Each player picks their files — the guitarist can keep just the tab.

Marking up

Everyone marks the same page

A band’s real knowledge lives in the margins — capo 2, watch me here, everyone in on the last chorus. Open a song in the browser and draw on it: highlights, text, circles, arrows, music symbols.

  • Live — open the same song on two computers; a mark appears on both.
  • Layers — band layers for everyone, the leader’s cues, and personal notes your bandmates don’t see unless they choose to.
  • Required layers — mark a layer as required and every player sees it on stage.
  • Marks stick to the music — change the chart, and they stay on their words.

Finding songs

Find a song by what it is

Tag songs the way the band talks about them — opener, slow blues, needs work — then search by title, artist or tag.

  • Combine tags — pick two, and only songs with both remain.
  • Suggestions with counts, so the band doesn’t end up with three spellings of the same tag.
  • One panel to tidy them — rename or merge, with the number of songs affected shown first.

Setlists and concerts

From setlist to every tablet

Drag the songs into order, add an intermission, change a key for tonight’s singer. Then “bake” the setlist: TroubaStack turns it into one concert file, and every tablet in the band is offered the new version.

  • Personal cues — each player marks what to get ready (an instrument, a mic), shown when the song starts.
  • Choose what shows — decide which layers are on when the concert opens.
  • One file for the whole band — each player sees their own view of it.
  • Print it — the running order as a sheet for the floor or the sound engineer, and the whole concert as a PDF with your marks, as a paper backup.

On stage

Made for a music stand, late at night

The concert is downloaded once and kept on the tablet. While you play, the app needs no network at all — no wifi, no signal, no problem. The whole screen is the music; one tap brings back the controls.

  • Page turns hands-free — a Bluetooth foot pedal (keyboard or MIDI), or the volume keys.
  • Four colour schemes — normal, warm, night and amber, for any light.
  • Facing pages on a wide tablet, or one long scrolling column.
  • A silent count-in in the song’s tempo, and a clock for the set.
  • Every song in two taps from the song list.
  • Hard to leave by accident — a stray swipe never ends the concert.

Jump marks

Tap the sign. Land on the passage.

A chart says D.S. al coda or back to the sign — on a tablet that used to mean swiping back through pages mid-song, hunting for a small symbol. A jump mark does it for you.

  1. Place a pair in the editor — where you jump from, and where you land. Both get the same sign and colour, so you match them by eye, as on paper.
  2. Check the direction — select either end to see which page the other is on; one button swaps them.
  3. Tap it on stage — confirm with “Go”, and you’re there.

Rehearsal notes

Write it on the stand. Find it at your desk.

Rehearsal is where the real corrections happen, and nobody puts the tablet down to open a laptop. So the tablet has a pencil: write on the page, and the note goes back to the editor, to be copied in properly later.

  1. Write on the tablet — right on the page you’re playing from.
  2. Send it — one tap, or automatically during a rehearsal.
  3. See it in the editor — on the page it was written on.
  4. Copy it in, then remove it — the note was a reminder; the mark is the real thing.

For developers

Open source, and built to be read

Apache-2.0, developed in the open in small reviewed steps. If you like clean architecture, honest documentation and real tests, you’ll feel at home.

  • Three modules, one job each An editor, a server that also “bakes” concerts, and a presenter — editing and performing fail in different ways, so they are different programs.
  • A modern, boring stack A single Go binary for the server; React + TypeScript for the editor; Kotlin + Compose Multiplatform for the app (Android today, iOS compiled in CI).
  • Architecture written down first Numbered invariants, a design note per subsystem, decision records, and an honest list of what a real band still can’t do.
  • Tested at every layer Go tests under the race detector, browser end-to-end tests with Playwright, Android unit tests, and an iOS compile — on every push.
  • One pixel pipeline What you see in the editor and what the tablet shows come from the same renderer.
  • Simple to self-host All state in one directory; a published Docker image; a plain config file with every option documented.

For the band’s tech person

Install it in a few commands

A home server or a small rented one is plenty. Your band’s data stays on it — in one folder you back up with tar. No account with anyone.

1 · The server

Docker Compose with automatic HTTPS (Let’s Encrypt). No need to clone anything — point your domain at the machine, then:

mkdir deploy && cd deploy
R=https://raw.githubusercontent.com/yoda-jm/troubastack/main/deploy
curl -fsSLO $R/docker-compose.yml
curl -fsSLO $R/Caddyfile
echo DOMAIN=band.example.org > .env
docker compose up -d

Open your domain, create your account, then your band — you are its admin. The image is on Docker Hub; on a home network without a domain, one docker run is enough (see the README).

2 · The tablets

Each player installs the Android app, then scans the band’s invite QR code to join.

On the tablet itself, tap here to download. The app also opens a concert file with no server at all.

Just trying it?

Run everything on your own computer with a demo band already set up.

make setup
make demo
# → http://localhost:8080  marie / demo

Needs Go 1.26+ and Node 24+ (and pdftoppm to bake PDFs).

Where packaging stands. The published server image is for regular PCs and servers (linux/amd64); on a Raspberry Pi or another ARM machine you build it from source for now. The Android app is not in a store yet: it is a test build from GitHub, so Android will ask you to allow installing it.
