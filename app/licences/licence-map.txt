# A101 — how a POM's <license> (its "name <url>", lower-cased) maps to an SPDX id: the first row whose text is a
# substring of it wins. A POM licence no row matches FAILS the build (naming the component), so a new kind of licence
# is added here once, on purpose; a new component with a known licence needs nothing.

chromium.googlesource.com/libyuv	BSD-3-Clause
